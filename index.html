03 / Philosophy

How I think about products

⚡

Start with friction

Every product begins with something that takes too long or feels too complicated. If I can cut the steps in half, it's worth exploring.

🎯

One job, done well

The best tools do one thing and nail it. Feature creep is the enemy. If it can't be explained in one sentence, it's too complex.

🚀

Ship, then polish

A working prototype in users' hands beats a perfect spec in a drawer. Real feedback teaches more than any amount of planning.
